# Brain Index

> Map of content. Every brain file listed with one line on what lives there.
> Pointers, never copies — facts live in exactly one file.

## Core

- [[BRIEF]] — what this project is, why it exists, scope and non-goals. Changes only on pivots.
- [[ARCHITECTURE]] — how the system is built: stack, patterns, gotchas. Updated when patterns change.
- [[ACTIVE]] — current focus, next steps, open questions. Rewritten every session.
- [[PROGRESS]] — append-only ledger of what got done, dated. Never edited backwards.
- [[DECISIONS]] — significant choices with rationale and rejected alternatives.
- [[LESSONS]] — hard-won anti-patterns. "Never X — because Y." Always loaded; every line earns its place.
- [[WORKFLOWS]] — recurring multi-step sequences spotted across sessions. Promoted to skills via /neo:train.
